# Ertugrul Ozkaya - Portfolio Website

A modern and responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive design
- Modern and clean interface
- Smooth scroll navigation
- Mobile-friendly menu
- Contact form
- Project gallery
- Social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome icons

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ertugrulozkaya/Portfolio-web.git
```

2. Navigate to the project directory:
```bash
cd Portfolio-web
```

3. Open `index.html` in your web browser.

## Usage

- The website is fully responsive
- All sections work with smooth scroll for easy navigation
- Burger menu becomes active on mobile devices
- Contact form is processed with JavaScript
